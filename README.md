# be-agentic-demo

A minimal blockchain, built from [`SPEC.md`](./SPEC.md) by a fleet of agents — the demo project for the **rig** multi-agent workflow.

The repo starts as a spec and nothing else. That's the point: watch it get built.

## Follow along at home

Clone this repo, open it in **Claude Code**, and run:

```
/demo
```

It walks you through the whole thing on your own machine and GitHub account:
set up the GitHub CLI (and the one extra permission it needs), make a copy you
own, install rig, spin up a board, then build the chain from `SPEC.md` —
the foundations first, then it **kicks off an epic that keeps building on its
own**. Come back later and the chain is taller than you left it.

You'll need [`gh`](https://cli.github.com) and [`cargo`](https://rustup.rs).

> Nothing is written to this upstream repo — everything lands in your copy.
