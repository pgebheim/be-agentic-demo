# be-agentic-demo

A minimal BFT blockchain, built from [`SPEC.md`](./SPEC.md) by a fleet of agents — the live demo project for the rig multi-agent workflow.

The repo starts empty on purpose: a spec, and nothing else. Watch it get built.

## The talk

The slides that frame this demo — *Step out of the loop* — live at
[`docs/talk.html`](./docs/talk.html). Open it in a browser (it's a single
self-contained file). To follow along yourself, run `/demo`.
