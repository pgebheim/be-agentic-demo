# be-agentic-demo

A minimal BFT blockchain, built from [`SPEC.md`](./SPEC.md) by a fleet of agents — the live demo project for the rig multi-agent workflow.

The repo starts empty on purpose: a spec, and nothing else. Watch it get built.

## The talk

The slides that frame this demo — *Step out of the loop* — are published at
**<https://pgebheim.github.io/be-agentic-demo/>** (source:
[`docs/index.html`](./docs/index.html), a single self-contained file). To
follow along yourself, run `/demo`.
